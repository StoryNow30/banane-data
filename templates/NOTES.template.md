# Notes opérateur

## Contexte

- Version Banane :
- Mode :
- Projet/portion (alias non sensible) :
- Date :

## Stratégie de collecte

Décrire la variété recherchée : placements déjà bons, corrections faibles/fortes, ambiguïtés, décorrélations, zones particulières, etc.

## Observations terrain

Consigner uniquement ce qui a été réellement observé. Séparer clairement :

- observation visuelle ;
- action humaine ;
- résultat Banane ;
- hypothèse d'interprétation.

## Cas remarquables

Pour chaque cas utile, noter part/cut si connu, rail concerné et raison de la correction.

## Incidents / limites

Indiquer les segments manquants, interruptions, exports incomplets, navigation inattendue ou toute autre anomalie susceptible d'affecter l'analyse.
